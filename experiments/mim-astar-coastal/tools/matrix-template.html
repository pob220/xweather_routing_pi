How to read this comparison

A quick failure is not a fast solution. Success-only timings can cover different cases; the common-success line uses exactly the same subset for all eight engines. Groups with few cases are descriptive examples, not evidence of a universal ranking. Holyhead departure variants are over-represented.

Route settings describe scenario intent. Distances are great-circle endpoint distances, not sailed lengths or measured coastal exposure. Expected rejection cases are visible but excluded from route-success statistics. R records no valid completion on a rejection case; the stopping reason still matters. Missing Tonga measurements are marked “not run”.

Six archived control columns reuse an earlier campaign after matching inputs, source and adapter behaviour. The earlier first-prototype column is excluded and replaced by the qualified prototype run. All clients use their supported weather adapters and GSHHG, not chart-depth authority. These data cannot measure OpenCPN UI overhead.

This file is self-contained and makes no network requests. The accompanying MATRIX.md, statistics.json and measurements.json give the tables and source receipts.
